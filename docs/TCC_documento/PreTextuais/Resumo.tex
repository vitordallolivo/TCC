\begin{resumo}
Este trabalho desenvolve um sistema de aquisição para ensaios de motores BLDC, que adquire as tensões e correntes de fase, aciona e controla o motor e se comunica por Ethernet com um \textit{software} de supervisão. A velocidade e o torque no eixo são estimados sem sensores mecânicos, por um observador por modos deslizantes embarcado no sistema. O sistema serve como ferramenta para a caracterização de conjuntos motopropulsores.

 \textbf{Palavras-chave}: Bancada de Ensaios; Motor BLDC; Observador por Modos Deslizantes; Aquisição de Dados; Sistema \textit{Sensorless}; Propulsão Elétrica.
\end{resumo}
