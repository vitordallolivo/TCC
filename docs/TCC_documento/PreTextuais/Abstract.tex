\begin{resumo}[Abstract]
 \begin{otherlanguage*}{english}
   This work develops an acquisition system for BLDC motor tests, which acquires the phase voltages and currents, drives and controls the motor and communicates over Ethernet with a supervisory \textit{software}. Shaft speed and torque are estimated without mechanical sensors by a sliding mode observer embedded in the system. The system serves as a tool for the characterization of electric propulsion assemblies.
   
   \textbf{Keywords}: Test Bench. BLDC Motor. Sliding Mode Observer. Data Acquisition. \textit{Sensorless} System. Electric Propulsion.
 \end{otherlanguage*}
\end{resumo}
